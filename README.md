# A股多因子选股系统

基于AKShare API实现的A股市场多因子选股系统，结合基本面、技术面和资金面多维度筛选优质股票。

## 1. 系统概述

本系统采用多因子选股策略，通过量化筛选方法从A股市场中筛选出符合投资要求的优质股票。系统整合了基本面分析、技术面分析和资金面分析三大维度，并通过可视化展示选股结果，帮助投资者更直观地理解筛选结果。

### 1.1 系统架构

本系统主要由三个部分组成：

1. **数据获取模块**：基于AKShare开源接口，获取股票基础数据、财务数据、资金流向、持股数据等
2. **选股策略模块**：实现多层次、多维度的选股逻辑
3. **可视化展示模块**：通过图表和报告展示选股结果

### 1.2 特点优势

- **多维度选股**：结合基本面、技术面、资金面等多角度分析
- **自适应API**：自动适配AKShare接口的版本差异
- **健壮数据获取**：带重试机制的数据获取，提高稳定性
- **综合评分机制**：多因子加权评分选出最佳股票
- **直观可视化**：多种图表展示选股结果

## 3. 选股策略说明

### 3.1 基本面初筛

基本面因子主要考察公司的基础价值与成长性：

- **高成长性**：选择近2年营收/净利润同比增速>20%
- **机构背书**：最近季度前十大流通股东中机构增持数量≥3家
- **市值优选**：总市值50-300亿元（兼顾流动性与爆发力）

### 3.2 技术面突破确认

技术面因子主要考察股价的走势特征与突破形态：

- **趋势通道**：日线收盘价站上50日均线且均线多头排列
- **形态突破**：周线出现杯柄形态/三角形突破，突破日成交量放大50%以上
- **波动率过滤**：过去1个月振幅≥15%（捕捉活跃股）

### 3.3 资金面验证

资金面因子主要考察市场资金对股票的认可程度：

- **主力资金**：当日主力净流入额>5000万元且连续3日净流入
- **北向加持**：北向资金持股比例周增幅≥0.5%
- **异动信号**：近期出现大宗交易溢价成交或龙虎榜机构席位买入

### 3.4 综合评分机制

系统对各项指标进行加权评分，总分最高16分，筛选分数10分以上的股票：

| 因子类别 | 因子描述 | 分值 |
|---------|---------|------|
| 基本面 | 高营收/利润增长 | 2分 |
| 基本面 | 机构持股达标 | 2分 |
| 基本面 | 市值符合要求 | 1分 |
| 技术面 | 站上均线 | 1分 |
| 技术面 | 均线多头排列 | 1分 |
| 技术面 | 波动率达标 | 1分 |
| 技术面 | 成交量放大 | 1分 |
| 技术面 | 形态突破 | 2分 |
| 资金面 | 主力资金净流入 | 2分 |
| 资金面 | 连续资金流入 | 1分 |
| 资金面 | 北向资金增持 | 2分 |
| 资金面 | 异动信号 | 2分 |

## 4. 使用方法

### 4.1 基本用法

1. 运行完整流程（选股+可视化）：
```bash
python run_stock_screening.py
```

2. 仅运行选股策略：
```bash
python run_stock_screening.py --select-only
```

3. 仅运行可视化分析：
```bash
python run_stock_screening.py --visualize-only
```

### 4.2 参数配置

可在`stock_selector.py`文件中修改`FILTER_PARAMS`和`MARKET_PARAMS`配置参数，自定义选股条件：

```python
# 市场相关参数
MARKET_PARAMS = {
    "start_date": (datetime.now() - timedelta(days=365)).strftime("%Y%m%d"),
    "end_date": datetime.now().strftime("%Y%m%d"),
}

# 筛选条件参数
FILTER_PARAMS = {
    # 基本面条件
    "growth_rate_min": 20.0,       # 最小增长率(%)
    "institutional_min": 3,         # 最小机构持股家数
    "min_market_cap": 5000000000,   # 最小市值(50亿)
    "max_market_cap": 30000000000,  # 最大市值(300亿)
    
    # 技术面条件
    "ma_days": 50,                  # 均线天数
    "amplitude_min": 15.0,          # 最小振幅(%)
    "volume_increase": 50.0,        # 成交量放大比例(%)
    
    # 资金面条件
    "main_inflow_min": 50000000,    # 最小主力净流入(5000万元)
    "north_increase_min": 0.5,      # 北向资金持股比例增幅(%)
}
```

### 4.3 输出文件

选股结果和可视化文件将保存在以下目录：

- `选股结果/`：保存选股CSV数据和JSON详细数据
- `选股结果/可视化/`：保存各类图表和汇总报告

## 5. 可视化结果说明

系统提供多种可视化图表展示选股结果：

1. **得分分布图**：展示所有选中股票的得分分布
2. **行业分布图**：展示选中股票的行业分布情况
3. **高分股票图**：展示得分最高的前10只股票
4. **增长率vs机构持股图**：散点图展示两个重要指标的相关性
5. **主力资金净流入图**：展示各股票的主力资金流入情况
6. **汇总报告**：提供全面的统计数据和分析结果

## 6. 注意事项

### 6.1 API兼容性

AKShare库的API可能会随版本更新而变化，系统内置了兼容性处理机制，但建议：

1. 定期更新AKShare库：`pip install --upgrade akshare`
2. 运行API测试脚本检查兼容性：`python akshare_api_test.py`
3. 参考`API_UPDATE_NOTES.md`了解API变更历史

### 6.2 数据限制

1. 免费API可能有访问频率限制，系统已实现重试机制，但仍可能遇到限制
2. 北向资金、机构持股等数据可能存在延迟或不完整
3. 部分复杂技术形态识别（如杯柄形态）采用简化算法，可能与专业判断有差异

## 7. 技术实现细节

### 7.1 数据获取

系统使用AKShare API获取多种数据：

- 股票基础信息：`ak.stock_zh_a_spot_em()`
- 历史行情数据：`ak.stock_zh_a_hist()`
- 财务数据：`ak.stock_financial_analysis_indicator()`
- 十大流通股东：`ak.stock_gdfx_free_top_10_em()`
- 资金流向：`ak.stock_individual_fund_flow()`
- 北向资金：`ak.stock_hsgt_fund_flow_summary_em()`
- 大宗交易：`ak.stock_dzjy_mrtj()`
- 龙虎榜：`ak.stock_lhb_detail_em()`

### 7.2 技术面指标计算

系统自动计算技术指标：

- 各周期移动平均线：MA5、MA10、MA20、MA50
- 振幅与波动率指标
- 成交量变化率
- 突破形态识别

### 7.3 文件结构

- `run_stock_screening.py`：主运行脚本，处理命令行参数
- `stock_selector.py`：实现选股逻辑和数据处理
- `stock_visualizer.py`：实现各类可视化功能
- `akshare_api_test.py`：API兼容性测试脚本
- `API_UPDATE_NOTES.md`：API更新记录
